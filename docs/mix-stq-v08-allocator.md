# MIX-STQ v0.8 결과 — 민감도 기반 레이어 선택은 효과가 없습니다 (음성 결과)

**작성일** 2026-08-30
**GPU 지출** $0.1613 (RTX 3090 61.3분, 파괴 완료)
**결론** allocator가 고른 레이어 집합은 naive "앞쪽 N개"보다 **통계적으로 나을 것이 없습니다.**

---

## 1. 예측 단계: 신호가 거의 없었습니다

OLMoE 16레이어 전체에서 IQ2 → LTC 강등 손상(damage)을 실측했습니다.
손상 = LTC 오차 − IQ2 오차, 레이어당 gate/up 각 96행 표본, 실제 imatrix.

| 항목 | 값 |
|---|---:|
| damage 최소 | 0.1905 (L0) |
| damage 최대 | 0.2024 (L9) |
| **전체 편차** | **평균의 6.1%** |
| allocator 6레이어 합산 손상 | 1.1511 |
| naive 6레이어 합산 손상 | 1.1678 |
| **예측 개선폭** | **1.43%** |
| 최선 vs 최악 배치 차이 | 2.76% |

레이어 선택은 극단적으로 다릅니다(겹침 1/6):

| 배치 | 레이어 |
|---|---|
| allocator 최선 | 0, 6, 10, 11, 13, 14 |
| naive 앞쪽 6개 | 0, 1, 2, 3, 4, 5 |
| allocator 최악 | 2, 3, 4, 5, 7, 9 |

**선택은 완전히 다른데 예측 손상 차이는 1.43%입니다.** 이 시점에서 이미 결과가 예상됐습니다.

## 3. 왜 무관한가

OLMoE의 expert 텐서는 **모든 레이어에서 통계적으로 거의 동일합니다.**
v0.3c에서 이미 관측했습니다: STQ 오차의 레이어 간 편차가 평균의 4.4%였고,
깊이 상관은 r=+0.685이지만 절대 편차가 미미했습니다.

v0.8은 그 관측의 논리적 귀결입니다. 텐서가 동질적이면 어느 것을 강등해도 같은 비용입니다.
HY4가 29/48 레이어를 나눈 것이 재현하기 어려웠던 이유도 이것으로 설명됩니다 —
**신호가 약하면 imatrix 노이즈가 순위를 지배합니다.**

### 이 발견이 설계에 주는 의미

설계 §5.4의 allocator 논의를 **단순화해야 합니다.** v0.7에서 top-k == Lagrangian을
확인했고(정교한 최적화 불필요), v0.8은 **선택 자체가 불필요**함을 보입니다.
동질적 MoE expert에서는 예산만 정하면 되고, 어느 레이어인지는 중요하지 않습니다.

단, 이는 **OLMoE에 한정된 결론**입니다. Qwen3.5처럼 hybrid attention이나 shared expert가
있는 구조, 또는 레이어별 크기가 다른 모델에서는 다를 수 있습니다.

## 6. 현재 시점의 정직한 요약

**확립된 것**
- 3:4 제약은 실제 가중치에서 손실입니다 (자연 0 = 0.313 vs 강제 0.250)
- LTC는 동일 비트에서 STQ1_0보다 재구성 오차가 낮고(+6.5~7.2%), 품질도 우세합니다 (v0.6)
- 바이트 형식이 이득을 보존하며 STQ1_0과 호환됩니다
- LTC low3(1.9688 bpw)는 uniform IQ2(2.0625 bpw)와 **동등한 품질을 4.5% 적은 비트로** 제공합니다
- 무릎은 1.9688과 1.8750 bpw 사이에 있습니다

**증명되지 않은 것**
- LTC가 IQ2보다 **품질이 좋다**는 것 (CI가 0을 포함)
- 레이어 선택 최적화의 가치 (v0.8이 음성)
- 실제 태스크 정확도(MMLU 등), 커널 속도, VRAM 이득

**즉 MIX-STQ의 현재 가치 제안은 단 하나입니다: 동일 품질에서 4.5% 작은 파일.**
그 이상을 주장할 근거는 아직 없습니다.
